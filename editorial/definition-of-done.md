# Definition of Done

- [ ] Objectives match the chapter.
- [ ] Terminology follows the style guide.
- [ ] Commands and code samples were tested.
- [ ] Version-sensitive statements include a source or version note.
- [ ] Diagrams include source, caption, and alt text.
- [ ] Worked examples include acceptance criteria.
- [ ] Labs include verification, failure injection, and cleanup.
- [ ] Common failure modes are documented.
- [ ] Security implications are addressed.
- [ ] Cross-references resolve.
- [ ] Glossary terms are updated.
- [ ] Technical review is complete.
- [ ] Copy edit is complete.
