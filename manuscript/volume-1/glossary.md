# Glossary

## Backpressure
A system's response when work arrives faster than downstream components can process it.

## Credential
Stored authentication material used by a workflow to access another system.

## Execution
One attempt to run a workflow from a trigger through its reachable nodes.

## Idempotency
The property that repeating an operation produces the same intended effect as performing it once.

## Item
The basic unit of structured data passed between n8n nodes.

## Trigger
The event source or condition that starts a workflow execution.

## Workflow
A directed graph of nodes that performs work in response to a trigger.
